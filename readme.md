# Angular libraries monorepo

## Description

`@jchpro` libraries for Angular apps. This is very much work in progress.

Visit my [example app page](https://ng.jchpro.pl) for a quick start, refer to code comments for more.

## Libraries

- `@jchpro/ngx-common` [Common parts for the Angular apps](/projects/@jchpro/ngx-common/readme.md)
- `@jchpro/ngx-kit` [Admin-app UI kit with the jchPRO look](/projects/@jchpro/ngx-kit/readme.md)

## Installation

```shell
$ npm install
```
