Overview

Simple file selector, which replaces native <input [type]="file"/> with Material-styled buttons.
Additionally, you can place file dropzone next to it and bind them to work together easily for users convenience.

Standalone selector

With dropzone

Dropzone must be attached to the selector. It automatically hides selector's info section and displays it using the same rules in its own container.

Customizing labels and handling multiple languages

To customize the labels used in selector and dropzone, extend ProFilesIntl and provide it using provideFilesIntl.
The same class can be used to handle translation of your messages into multiple languages.
