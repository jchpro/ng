Overview

The application frame: a header, a collapsible sidenav, an optional footer and the main content area. The sidenav is docked on wide screens and turns into a focus-trapped overlay on narrow ones, with a toggle button added to the header automatically.

This documentation site itself is built with it.

Setup

1. Install

npm install @jchpro/ngx-kit @angular/cdk @lucide/angular @jchpro/ngx-common

2. Include the styles

Shell layout CSS ships as one global stylesheet, next to the design tokens it relies on.

3. Mark the root component

Compose the shell directly in your app's root component, not in a routed one, and mark that component with KitShellRoot. The shell warns in the console if the marker is missing.

4. Compose the layout

The router outlet is usually the main content.

5. Add navigation (optional)

KitShellNavItems placed in the header become top navigation, and ones grouped in KitShellNavSections inside the sidenav become the sidebar menu. Import KitShellNavItem and KitShellNavSection alongside the rest. Keep top navigation to 3-4 items, on mobile it moves to a second row of the header.

Components

Name Description
KitShell The frame itself, caps the layout at viewport height so only the content area scrolls
KitShellRoot Marker directive for the app's root component, required for the shell styles to apply
KitShellHeader Top bar, hosts the sidenav toggle on mobile and renders top navigation from projected nav items
KitShellSidenav Docked or overlay side panel, depending on screen width
KitShellFooter Optional bar pinned below the content
KitShellNavSection Titled, optionally disabled group of nav items for the sidenav
KitShellNavItem A navigation entry: link (with optional active-match options) or click action, optional icon and disabled state, rendered by its section or the header
KitShellState Injectable shell state: sidenav mode and open state, closeSidenav()
KIT_SHELL_MOBILE_QUERY Injection token overriding the breakpoint at which the sidenav collapses, 768px by default
KIT_SHELL_LABELS, provideKitShellLabels() The only text the shell renders, the accessible name of the sidenav toggle, English by default. Override it app-wide, with provideKitLabels('pl'), or per header with the toggleNavigationLabel input
