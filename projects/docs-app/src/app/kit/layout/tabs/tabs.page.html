Overview

Sections of one page where the route is the state, so a reload or a shared link opens the same section: a <nav> of links, with aria-current="page" on the active one. Plain classes, not a component. This very page is built with it, the row above the content is kit-tabs.

Try it

Without a router the active link is kit-tabs__link--active, the look is the same. The count is kit-tabs__count. Narrow the window and the row scrolls sideways.

Classes

Class Use
kit-tabs The <nav>: the divider under the row, horizontal scroll when the links don't fit. Give it an aria-label
kit-tabs__link A link. aria-current="page" (or --active) draws the 2px line and takes primary ink
kit-tabs__count An optional counter after the label
