Overview

Two small helpers for forms built with Angular's Signal Forms. The kit doesn't wrap the controls: a native input with kit-field__control is the control, and these cover the two things around it. @angular/forms is an optional peer dependency, only needed for them.

Field error

<kit-field-error [field]="form.name" /> is the kit-field__error line under a control: the first error of the field, with the icon, once the field has been touched (the person left it, or tried to submit). The text is chosen by the kind of the error from KIT_FORM_LABELS (English and Polish, provideKitLabels() wires both). [messages] adds the text of a custom kind, or rewords a built-in one; an error of an unknown kind shows its own message.

Resetting a form

form().reset() clears what Signal Forms knows, but not what the browser remembers about the fields a person has been in: an emptied required field stays :user-invalid (red) until the native form is reset as well. resetKitForm(form, formElement, value?) does both, native reset first so the form's values are written back.

Components and functions

Name What it does
KitFieldError <kit-field-error [field] [messages] />: the first error of a touched field, as a kit-field__error line
KIT_FORM_LABELS, provideKitFormLabels() The messages by kind: required, email, min, max, minLength, maxLength, pattern, with {min} and {max}, and a fallback
resetKitForm() Resets the Signal Forms form and the native <form>
