Overview

A native <input type="file"> is styled as a field, see Multi-line, choice and files in Text and values. For uploads, dropping a file on a bigger area is the more common experience: kit-dropzone is a label with the input stretched invisibly over it, so a click and the keyboard work with no extra code, and the kitDropzone directive adds the drop. Hover, focus and a file over the zone share one look.
