Overview

Contextual menus opened from a button, on CDK overlays. Keyboard navigation, focus handling and ARIA come from the CDK menu, the kit adds consistent styling and a small API. There are no submenus for now.

Setup

Menus render in the CDK overlay container, which needs its structural styles once in your global stylesheet. The menu look itself is part of primitives.

Usage

Point [kitMenuTriggerFor] at an <ng-template> whose root is a kitMenu. Items are buttons or links, mark destructive ones with danger.

API

Name Description
KitMenuTrigger [kitMenuTriggerFor] on any element, with [kitMenuPosition], [kitMenuTriggerData], (kitMenuOpened) and (kitMenuClosed). Opens below the trigger by default and flips when there is no room
KitMenu The panel, on the root element of the template
KitMenuItem A button or link inside the panel, danger and [disabled] inputs, closes the menu when activated
[checked], checkbox On an item: makes it a choice (menuitemradio, or menuitemcheckbox with checkbox) exposing aria-checked. The state is yours, show it with an icon
.kit-menu__separator Class for an <hr> between groups of items
.kit-menu__label Class for a non-interactive group heading, the stand-in for submenus: one flat menu, a label per group
.kit-btn--icon Button modifier for a square, icon-only trigger, give it an aria-label
