Overview

Text in the kit comes in two registers, kept apart on purpose. The interface scale is for what components and admin pages are made of: titles of pages, cards and dialogs, labels, secondary text. It is compact, headings sit close to the 14px body. Prose is for long-form content, as on these pages: free-flowing paragraphs, lists and tables under headings that have to stand out from the text, so its headings are larger.

Both are needed. Prose headings in a card or a form would crowd it, and the interface scale on a page of text makes the sections hard to tell apart. An admin page uses only the interface scale, its headings coming from components such as the page header and the card title. Prose appears where a page has a block of written content: help text, terms, release notes, documentation.

Prose styling is applied to the whole content area of these pages, to plain unclassed elements only, so a kit class always wins. The prose heading sizes are provisional tokens, see #10. How the kit offers prose (probably an opt-in container class) is not decided yet, it waits until the missing elements below are styled.
