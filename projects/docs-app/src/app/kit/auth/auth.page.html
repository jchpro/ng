Overview

The views for an app with local sign-in: KitLogin, KitForgotPassword and KitSetPassword, which serves both a password reset and accepting an invitation. They render and validate the form and emit what was entered. Making the request, reading the token from the URL and navigating stay in your app, the kit has no auth logic, no router and no @angular/forms dependency.

Under them are the pieces they are built from, KitAuthCard, KitPasswordToggle and a few classes, so a form on your own model, say signal forms, gets the same look.

Setup

The look is part of primitives. .kit-auth-page centers the card in the viewport; inside a shell, its content area drops its padding for it.

Sign in

identifierType is 'email' (default) or 'username'. While busy the button shows a spinner and the fields turn read-only, and error appears above the form in a live region. Empty fields are caught by the kit and focus goes to the first invalid one.

Forgot password and set password

KitForgotPassword emits requested, then you set sent to swap the form for a confirmation that does not reveal whether the account exists. KitSetPassword asks for the password twice and takes flow="reset" or flow="invite", which only changes the wording. minLength is announced under the field, and fields projected as kitAuthFields join the form.

Your own form

KitPasswordToggle adds the show/hide button to the native input inside it by flipping its type, so it works with any way of binding that input. Either icon can be replaced by projecting an element marked kitIcon="show" or kitIcon="hide". Put [kitBusy] on the card to cover it while a request is out.

Labels

Every string, the show/hide button's accessible name included, is in KIT_AUTH_LABELS, set with provideKitAuthLabels(), provideKitLabels('pl') or a view's own labels input. Two messages have a placeholder the view fills in, {{ '{min}' }} and {{ '{identifier}' }}.

API

Name Description
KitLogin Sign-in form. Inputs identifierType, showRememberMe, busy, error, labels; output submitted with KitLoginCredentials
KitForgotPassword Asks for the account to send reset instructions to. Inputs identifierType, busy, sent, error, labels; output requested
KitSetPassword New password twice, for flow 'reset' or 'invite'. Inputs minLength, busy, error, labels; output submitted
KitAuthCard The shell of every view: heading, description, error, slots kitAuthLogo and kitAuthFooter
KitPasswordToggle Show/hide button for the password input inside it, with kitIcon slots show and hide
KitIcon The [kitIcon] marker for an element that replaces a built-in icon
KIT_AUTH_LABELS Injection token for every string of the views, with provideKitAuthLabels() and the _EN / _PL sets
