Overview

Every string the kit shows, visible text and accessible names alike, goes through a per-feature labels token with English defaults. The kit has no i18n dependency, not even an optional one: the labels are plain strings, you bring the translations. The closest layer wins: the defaults, then the app-wide labels, then the call or instance's own option.

App-wide

provideKitLabels('pl') switches every feature to a complete set, provideKitDialogLabels() and its siblings override single strings. Providers apply in order, so the language comes first.

A language that lives in a service

providers is listed before any injector exists, so a service can't be injected there. Give provideKitLabels() a factory returning the language signal instead: it runs in an injection context, once, and all the features follow the signal as the language changes.
