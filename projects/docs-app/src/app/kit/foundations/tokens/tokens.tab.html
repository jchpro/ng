Overview

Design tokens are CSS custom properties prefixed --kit-*, light and dark. This tab shows the ones that are worth seeing, as they render in the current scheme. The rest, with the rules for using them, are in the library's docs/theming.md.

Surfaces

Four backgrounds, each with a job. Text and control edges are checked against every one of them by npm run check:contrast, so --kit-ink-primary, --kit-ink-muted and --kit-border-control are safe on all four.

@for (surface of surfaces; track surface.token) {
--kit-surface-{{ surface.token }} {{ surface.use }} Muted ink on it
}
