Overview

ScriptLoaderService.load(url) loads an external script on demand, a captcha or an analytics SDK that a page needs only sometimes. It appends the <script> to the head over the DOCUMENT token and answers with a Promise<void> that resolves when the script has loaded.

  • A URL loads once. Calls made while it is still loading get the same promise, so none of them resolves before the script is really there, and a call after it has loaded resolves at once.
  • A script that is already in the document, by its src or by the id option, counts as loaded.
  • A failure rejects with a ScriptLoadError (it has the url) and takes the element out, so the next call tries again.
  • attributes adds to the element what the SDK asks for: integrity, crossorigin, nonce, data-*.
