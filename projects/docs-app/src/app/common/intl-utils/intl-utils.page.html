Overview

This library provides a set of pipes for formatting dates, times, numbers and currencies in different locales.
It builds on top of Intl API.

Configuration

Everything will work automatically using default options with any configuration. The locale read from the navigator.language property will be used.
If you want to override the configuration use provideIntlConfig() in the app config. See example below.

The locale will be exposed in the IntlService as as Signal. Now you can inject the service wherever you use the pipes.
Because the pipes are pure they need to be passed the locale as a parameter, that's what the IntlService is for.
