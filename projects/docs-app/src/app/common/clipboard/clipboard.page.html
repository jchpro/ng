Overview

ClipboardService.copy(text) puts text on the clipboard and answers with a Promise<boolean>. It reads the browser from the WINDOW token and never throws: a page without the clipboard permission, or on an insecure origin, gets false, so the caller can show the text for the person to copy by hand.
