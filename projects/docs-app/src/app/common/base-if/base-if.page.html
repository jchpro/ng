Overview

Base class for building your own *ngIf-like structural directives, driven by any boolean-emitting stream instead of a plain input. Extends Reactive, so its subscriptions are cleaned up automatically once your directive is destroyed.

The contract is simple: assign a Subject<boolean>-like source to this.renderBinding, then call this.bindRendering() once your directive has finished its own initialization. From then on, the embedded view is created whenever the bound stream emits true, and cleared on false.

Usage

Usage in a template is exactly like a built-in structural directive: <div *appIfOnline>...</div>
