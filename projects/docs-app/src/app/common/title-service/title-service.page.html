Overview

Wrapper around Angular's Title service, configured with provideBrowserTitle.

This documentation site itself is built with it: watch the browser tab title as you navigate between pages, it's formatted with a  | @jchpro/ngx postfix, set up in app.config.ts.

Configuration

If observeRouteData is enabled, the service observes NavigationEnd and reads { title?: string; } from the resolved route's data, setting it automatically.
See route data in app.routes.ts for an example of providing the title this way.

Manual usage

Inject TitleService to set the title yourself, the formatFn from the configuration still applies:

Method Description
titleService.set('Start') Sets the title, formatted with formatFn if configured
titleService.get() Returns the raw title, as currently set on the document
