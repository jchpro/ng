## Installation

Required peer dependencies are:

- `@angular/cdk`
- `@angular/common`
- `@angular/core`
- `@angular/material`
- `@angular/material`
- `@jchpro/ngx-common`

```shell
npm i @jchpro/ngx-admin
```
